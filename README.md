Jill of the Jungle (1992) Android
=====================

This is a source port of the original DOS game “Jill of the Jungle” for Android. Added various fun and quality of life features.  

You will need the game files from a licensed copy in order to play it.  

Game Files
-------
Place files onto your device in an accessible folder.  
.sha, .vcl, .mac, .dem, .ddt, jill.dma, all numbered files 0-50.  
You can just copy the whole folder if you don't want to sort through.  
You can use the game files for specific episodes or all three for best experience.  
Recommend the game files from the GOG version.  

On first launch the game will ask you to select the folder with the files. If it closes you are not using the correct version of the files.  

Controls
-------
Auto show/hide on-screen touch controls.  
Optimized for handhelds.  
The few controls can be remapped in-game.  

Android Handhelds / Retroid Devices:  
Make sure controller style is set to Retro or whatever your devices default is. Ntndo style as opposed to Xbox style, swipe down menu to access these options.
