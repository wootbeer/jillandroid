## [0.1 (9-18-2026)]

### Added
Jill of the Jungle, but with features on Android
- Gamepad support
- Basic touch support
- Nuked-OPL3 audio support
- Content file selector
- Episode selector
- Gamepad rebinding
- Various menu navigation
- Force 4:3 mode, use to force a 4:3 scale adding black bars
- If you are using a 4:3 device already like a Nova you don't need to enable this
- Minimal HUD display mode, true widescreen, shows more of the play field
- Sound/Music level controls
- Cheat menu: god mode, all items in all episodes, etc
- Enhancement menu: clothing colors, attack speed, movement speed, etc
- Mirror mode, WIP
- And much more

### Changed
- Removed BBS Info option
- Added android keyboard to noisemaker screen so it can be used



### Fixed
- Various quality of life and bug fixes
- Fixed noisemaker screen
- Fixed Demo feature
